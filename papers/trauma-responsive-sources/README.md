# רשימת מקורות שפיטים: הוראה מודעת טראומה בישראל (2021–2026)

רשימה מוערת של 12 מאמרים בעברית ו-9 מאמרים באנגלית (ועוד 6 חלופות), שפיטים, בגישה פתוחה,
מחמש השנים האחרונות ובהקשר ישראלי, כמקורות נלווים לספר *Becoming Trauma Responsive*
(Lane, Chow, Hambrick & Earl, 2025).

- `trauma-responsive-sources.docx` — המסמך הסופי (Word, מימין לשמאל).
- `content.txt` — תוכן המסמך בתבנית הטקסט הפשוטה.
- `build.js` — סקריפט היצירה (`NODE_PATH=<path-to-node_modules> node build.js out.docx`, דורש `docx@9`).
