# دور الألعاب الحركية في تعليم الرياضيات للمرحلة الابتدائية وتحسين الفهم والتحصيل

بحث أكاديمي باللغة العربية (نحو 7,400 كلمة) مُعدّ وفق هيكل العمل الأكاديمي المطلوب:
غلاف، فهرس محتويات، ملخص، قائمة جداول، مقدمة، إطار نظري ودراسات سابقة، أسئلة البحث،
منهجية (منهج نوعي، مقابلات شبه مبنية مع 10 معلمين)، نتائج، مناقشة واستنتاجات، مراجع APA، ملاحق.

## الملفات

- `kinesthetic-games-math-primary.docx` — الملف النهائي (Word، اتجاه من اليمين إلى اليسار).
- `content.txt` — نص البحث بصيغة ترميز بسيطة (`#` عناوين، `>` اقتباس مزاح، `- ` نقاط، `1. ` ترقيم، `TABLE…ENDTABLE` جداول، `REF`/`REFEN` مراجع).
- `build.js` — سكربت توليد ملف Word من `content.txt` باستخدام مكتبة `docx`.

## إعادة التوليد

```bash
npm install docx@9
node build.js kinesthetic-games-math-primary.docx
```

## ملاحظات

- فهرس المحتويات حقل تلقائي؛ عند فتح الملف في Word اضغط «نعم» لتحديث الحقول (أو F9).
- بيانات الغلاف (اسم الجامعة، الطالب، المشرف) موضوعة بين أقواس مربعة لاستكمالها.
- فصل النتائج مكتوب بوصفه نموذجاً كاملاً لمقابلات نوعية، ويجب استبداله أو تأكيده ببيانات ميدانية حقيقية قبل التسليم.

## بحث السمينار (النسخة المبنية على المقابلات الفعلية)

- `kinesthetic-games-seminar.docx` — بحث السمينار الكامل (نحو 10,300 كلمة) المبني على ثماني مقابلات فعلية مع معلمات رياضيات في النقب، وفق هيكل العمل الأكاديمي وقواعد APA 7.
- `kinesthetic-games-seminar-he.docx` — הגרסה העברית המלאה של עבודת הסמינריון (כ-43,000 מילים כולל נספח ג': תמלילי שמונת הראיונות בתרגום לעברית; גוף העבודה כ-10,200 מילים, גופן David 12, רווח כפול, שוליים 2.5 ס"מ, תגי שפה he-IL ללא סימוני איות). המקור: `seminar-he.txt`, הכריכה: `seminar-he-cover.txt`. בנייה: `DOC_TOC_TITLE="תוכן עניינים" DOC_BIDI_LANG=he-IL AR_FONT=David ... node build-seminar.js kinesthetic-games-seminar-he.docx seminar-he.txt`.
- הגרסה העברית כוללת 12 מאמרים עבריים שפיטים בגישה פתוחה מהשנים 2021–2026 (מחקר ועיון בחינוך מתמטי, דפים, הייעוץ החינוכי, רוח הספורט, חוקרים@הגיל הרך, חמדעת, עיונים במינהל ובארגון החינוך) ושני מקורות שסיפקה הסטודנטית (בן-דוד קוליקנט וברוזה, 2014; בשארה, 2016). שדות שלא אומתו מול הקובץ המקורי (מספרי עמודים בחלק מהפריטים, סוף הכותרת אצל קולושי-מינסקר, כתיב שם המחברת השנייה אצל ויצמן בן-דוד ואחרים, שנת גיליון 3 של מחקר ועיון) מסומנים בתשובה למשתמש ודורשים בדיקה מול ה-PDF.
- `seminar.txt` — نص البحث بصيغة الترميز البسيطة؛ `seminar-cover.txt` — صفحة الغلاف؛ `build-seminar.js` — سكربت التوليد (يقبل متغيرات البيئة `AR_FONT`, `DOC_BODY`, `DOC_BODY_CS`, `DOC_LINE`, `DOC_MARGIN`, `DOC_COVER_FILE`, `DOC_BIDI_LANG`, `DOC_TOC_TITLE`).
