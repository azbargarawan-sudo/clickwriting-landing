# דוגמאות סמינריון, פסיכולוגיה ניסויית

התיקייה כוללת עבודות מחקר (סמינריון) בפסיכולוגיה ניסויית, שנכתבו לפי הנחיות
המטלה: מבוא ורקע תיאורטי, השערות, שיטה, תוצאות, דיון, רשימת מקורות ונספחים.

## הקבצים

### [`seminar-psychology-hope.docx`](./seminar-psychology-hope.docx), תקווה

- **משתנה תלוי:** תקווה, נמדדת בשאלון התקווה של סניידר.
- **משתנה בלתי-תלוי (3 רמות):**
  1. כתיבה על "העצמי הטוב ביותר האפשרי"
  2. היזכרות במטרה שהושגה בעבר
  3. ביקורת (תיאור יום שגרתי)
- **מדגם:** N=33 (11 בכל תנאי), הקצאה אקראית.
- **ניתוח:** ניתוח שונות חד-כיווני + השוואות Tukey.

### [`seminar-psychology-self-efficacy.docx`](./seminar-psychology-self-efficacy.docx), חוללות עצמית

- **משתנה תלוי:** חוללות עצמית כללית, נמדדת בשאלון NGSE.
- **משתנה בלתי-תלוי (3 רמות):** חוויית שליטה, חשיפה עקיפה, ביקורת.
- **מדגם:** N=33, ניתוח שונות חד-כיווני + Tukey.

## מבנה כל קובץ

שער, תוכן עניינים, תקציר, מבוא ורקע תיאורטי, השערות, שיטה
(משתתפים, כלים, הליך), תוצאות (טבלה וגרף), דיון (כולל מגבלות והצעות
למחקר עתידי), רשימת מקורות, נספחים (השאלון והוראות המניפולציה).

> הערה: הנתונים בעבודות הם נתוני דוגמה, להמחשת מבנה הדוח והניתוח הסטטיסטי.
> יש למלא בשער את פרטי המגיש/ה לפני הגשה, ולעדכן את תוכן העניינים בפתיחת הקובץ ב-Word.
