# דוגמת סמינריון — פסיכולוגיה ניסויית

הקובץ [`seminar-psychology-self-efficacy.docx`](./seminar-psychology-self-efficacy.docx)
הוא דוגמה לעבודת מחקר (סמינריון) בפסיכולוגיה ניסויית, שנכתבה על-פי הנחיות המטלה
המצורפות (מבוא ורקע תיאורטי, השערות, שיטה, תוצאות, דיון, רשימת מקורות ונספחים).

## תקציר התכנון המחקרי

- **משתנה תלוי:** חוללות עצמית כללית, נמדדת באמצעות שאלון NGSE.
- **משתנה בלתי-תלוי (3 רמות):** סוג המקור לחוללות עצמית —
  1. חוויית שליטה (היזכרות בהצלחה אישית)
  2. חשיפה עקיפה (קריאת עדות של עמית מצליח)
  3. ביקורת (משימת כתיבה ניטרלית)
- **מדגם:** N=33 (11 בכל תנאי), הקצאה אקראית.
- **ניתוח:** ניתוח שונות חד-כיווני (One-Way ANOVA) + השוואות מרובות (Tukey).

## מבנה הקובץ

שער · תוכן עניינים · תקציר · מבוא ורקע תיאורטי · השערות · שיטה
(משתתפים / כלים / הליך) · תוצאות (טבלה + גרף) · דיון (כולל מגבלות והצעות
למחקר עתידי) · רשימת מקורות · נספחים (השאלון והוראות המניפולציה).
