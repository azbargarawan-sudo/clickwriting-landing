# דוגמאות סמינריון, פסיכולוגיה ניסויית

התיקייה כוללת עבודות מחקר (סמינריון) בפסיכולוגיה ניסויית, שנכתבו לפי הנחיות
המטלה: מבוא ורקע תיאורטי, השערות, שיטה, תוצאות, דיון, רשימת מקורות ונספחים.
שתי העבודות כוללות טבלאות פלט וגרף בסגנון SPSS (שחור-לבן), נספח שאלון מלא,
ורשימת מקורות אמיתית ומאומתת, המשלבת מקורות שפיטים בגישה פתוחה וחדשים,
בעברית ובאנגלית.

## הקבצים

### [`seminar-psychology-hope.docx`](./seminar-psychology-hope.docx), תקווה

- **משתנה תלוי:** תקווה, נמדדת בשאלון התקווה של סניידר.
- **משתנה בלתי-תלוי (3 רמות):** כתיבה על "העצמי הטוב ביותר האפשרי",
  היזכרות במטרה שהושגה בעבר, וביקורת (תיאור יום שגרתי).
- **ניתוח:** One-Way ANOVA + Tukey. פלט SPSS: Descriptives, ANOVA,
  Multiple Comparisons, וגרף ממוצעים עם רווחי סמך.

### [`seminar-psychology-self-efficacy.docx`](./seminar-psychology-self-efficacy.docx), חוללות עצמית

- **משתנה תלוי:** חוללות עצמית כללית, נמדדת בשאלון NGSE.
- **משתנה בלתי-תלוי (3 רמות):** חוויית שליטה, חשיפה עקיפה, וביקורת.
- **ניתוח:** One-Way ANOVA + Tukey, באותו פורמט פלט SPSS.

## מבנה כל קובץ

שער, תוכן עניינים, תקציר, מבוא ורקע תיאורטי, השערות, שיטה
(משתתפים, כלים, הליך), תוצאות (טבלאות פלט SPSS וגרף), דיון (מגבלות והצעות
למחקר עתידי), רשימת מקורות, נספחים (השאלון המלא עם סולם התשובות והוראות
המניפולציה).
