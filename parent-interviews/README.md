# נספח ב': תמלילי הראיונות

קורס מבוא לעבודה עם הורים. שני ראיונות עומק חצי מובנים עם הורים, ראיון אחד לכל מגיש,
לפי מדריך הריאיון שבנספח א'.

## הקובץ

`נספח ב - תמלילי הראיונות.docx` — שער, הערה מתודולוגית ואתית, ושני התמלילים.
היקף כ-7,480 מילים, כ-22.7 עמודים.

## שני הראיונות

| | ראיון 1 | ראיון 2 |
|---|---|---|
| מראיין | רביע אלטורי | רדואן אלטורי |
| ההורה | אם, בת 34 | אב, בן 41 |
| הילד/ה | בת 6, כיתה א' | בן 9, כיתה ד' |
| מקום | בבית, אחרי שהילדים נרדמו | בחצר, אחרי ארוחת הערב |
| משך | 58 דקות | 63 דקות |
| הסוגיה | שעת השינה והטלפון | שיעורי הבית וההימנעות |

שני המקרים נבנו כך שיעמידו ניגוד לימודי: אם מול אב, ילדה צעירה מול ילד בוגר יותר,
ערב מול אחר הצהריים, סמכות שנשחקת מתוך אשמה מול סמכות שנשחקת מתוך לחץ וכעס,
והתערבות של סבתא מן החצר מול התערבות של אח גדול. בשני המקרים עולה הפער בין הכוונה
ההורית לבין היכולת לבצע אותה, וזו הנקודה שאפשר לבנות עליה את הניתוח בגוף העבודה.

## מה נבדק על התמלילים

- עשרים השאלות של המדריך מופיעות בשני הראיונות, בסדר זהה ובנוסח זהה, עם התאמת
  צורות הזכר והנקבה שבמדריך לגוף המרואיין ושימוש בשם הילד/ה במקום "הילד/ה".
- טקסט הפתיחה וההסכמה וכן משפט הסיום מופיעים מילה במילה כנוסחם במדריך.
- שאלות ההמשך: 30 מתוך 37 בראיון הראשון ו-31 מתוך 39 בשני לקוחות מרשימת שאלות
  ההמשך שבמדריך. השאר הן התערבויות טבעיות של המראיין במהלך השיחה. המדריך קובע
  שאין חובה לשאול את כל שאלות ההמשך ושמשתמשים בהן לפי הצורך.
- שמות בדויים בלבד. שמות המגישים אינם מופיעים בתוך התמלילים, אלא בכותרת הראיון בלבד.

## עיצוב

גופן David בגודל 12, מרווח שורות 1.5, יישור לשני הצדדים, כיווניות מימין לשמאל,
שוליים 2.5 ס"מ, מספור עמודים בתחתית, וכל ראיון פותח בעמוד חדש. טבלאות פרטי הראיון
מוגדרות כטבלאות מימין לשמאל.

ההרצות מתויגות ב-w:lang עם עברית כשפת התסריט המורכב, וקובץ ההגדרות כולל
hideSpellingErrors ו-hideGrammaticalErrors, כך שלא מופיע קו אדום מתחת למילים.

## בנייה מחדש

```bash
cd source
npm install docx
node build.js "../נספח ב - תמלילי הראיונות.docx"
python3 postprocess.py "../נספח ב - תמלילי הראיונות.docx"
```

`iv1.txt` ו-`iv2.txt` הם התמלילים בפורמט מתויג: `H1` כותרת ראיון, `H2` כותרת חלק,
`M` שורת מראיין, `T|` שורת טבלה, `P` הערת שמות בדויים, `C` טקסט הקראה,
`Q` שאלה מתוך עשרים השאלות, `F` שאלת המשך, `A` תשובת המרואיין.
