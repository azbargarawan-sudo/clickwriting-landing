# סמינריון: יחסי הורים-גננת בחברה הבדואית

שאלת המחקר: כיצד משפיעה מערכת היחסים בין הורים לגננות על תחושת הביטחון והשייכות של ילדיהם בחברה הבדואית בישראל?

## קבצים

| קובץ | תוכן |
|---|---|
| `סמינריון - יחסי הורים גננת בחברה הבדואית.docx` | העבודה המלאה, מוכנה להגשה |
| `part1_intro.txt` | פרק ראשון: מבוא וסקירת ספרות |
| `part2_method_results.txt` | פרק שני: שיטה, ופרק שלישי: ממצאים |
| `part3_discussion.txt` | פרק רביעי: דיון ורפלקציה, ורשימת מקורות |
| `part4_appendix_a.txt` | נספח א': מדריך הריאיון |
| `part5_transcripts.txt` | נספח ב': תמלולי הראיונות, ונספח ג': הצהרת AI |
| `build_docx.py` | סקריפט הבנייה |

## בנייה מחדש

```
pip install python-docx
cat part1_intro.txt part2_method_results.txt part3_discussion.txt \
    part4_appendix_a.txt part5_transcripts.txt > seminar_full.txt
python3 build_docx.py seminar_full.txt "סמינריון - יחסי הורים גננת בחברה הבדואית.docx"
```

## סימון בקבצי המקור

| סימון | משמעות |
|---|---|
| `#` / `##` / `###` | כותרות ברמות 1 עד 3 |
| `#PAGEBREAK` | מעבר עמוד |
| `#TOC` | שדה תוכן עניינים |
| `#COVER` ... `#ENDCOVER` | עמוד שער ממורכז |
| `> טקסט` | ציטוט ארוך בכניסה תלויה, בלי מירכאות |
| `[REF] טקסט` | פריט ברשימת המקורות, הזחה תלויה |
| `[AR] טקסט` | פסקה בערבית |
| `[T] טקסט` | שורת תמלול |
| `[B] טקסט` | פסקה מודגשת |
| `| א | ב |` | שורת טבלה, השורה הראשונה היא הכותרת |

עיצוב פנימי: `**מודגש**` ו-`*נטוי*`.

## הראיונות

העבודה מבוססת על שלושה ראיונות אמיתיים שהוקלטו ותומללו. שמות המשתתפות והילדים הם שמות בדויים. ההקלטה של הריאיון הראשון נקטעה, והמגבלה מצוינת בפרק השיטה ובפרק הדיון.

הקובץ `../simulated-interviews-nibal.md` מכיל שלושה ראיונות **מדומים** שנכתבו כתרגול בלבד. הם אינם חלק מהעבודה ואין להגישם כנתוני מחקר.

## לבדיקה לפני הגשה

1. מספרי העמודים של המקורות אבו-גוידר (2025), נער וביברמן-שלו (2021) וגילת ואחרים (2017). אומתו בחיפוש בלבד.
2. סדר המחברות במקור אלעטאונה ואבריאל-אבני (2017).
3. השדות המסומנים "לא נמסר" בטבלת המשתתפות בפרק השיטה.
4. עמוד השער: שם המכללה ושם המסלול.
5. נספח ג': הצהרת השימוש בבינה מלאכותית, לפי הטופס הרשמי של הקורס.
6. טופסי ההסכמה החתומים והסרוקים, לפני כל תמלול בנספח ב'.
7. רענון תוכן העניינים ב-Word: לחיצה ימנית על הטבלה ואז Update Field.
