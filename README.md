# כתיבה בקליק — אתר + מערכת ניהול הזמנות

אתר שיווקי (Landing Page) לשירות עזרה בעבודות אקדמיות, יחד עם **מערכת מלאה לניהול הזמנות**:
טופס הזמנה לסטודנטים, ‏REST API בצד שרת, מסד נתונים, ופאנל ניהול מוגן בהתחברות.

## תכונות

- 🎨 **דף נחיתה** בעברית (RTL) עם עיצוב זהב, רספונסיבי, אנימציות.
- 📝 **טופס הזמנה** — הסטודנט משאיר פרטים (שם, טלפון, סוג עבודה, נושא, היקף, דדליין) והם נשמרים במסד הנתונים.
- 🔌 **REST API** מלא (יצירה / רשימה / עדכון סטטוס / מחיקה).
- 🔐 **פאנל ניהול** (`/admin.html`) מוגן בהתחברות — צפייה בהזמנות, **חיפוש חופשי, מיון עמודות**, סינון לפי סטטוס, עדכון סטטוס ומחיקה.
- 📊 **דשבורד סטטיסטיקות** — הזמנות לאורך זמן, פילוח לפי סוג עבודה ולפי סטטוס (תרשימים).
- 🔔 **התראות אוטומטיות** על כל הזמנה חדשה — WhatsApp / אימייל / Webhook (אופציונלי, לפי הגדרה).
- ✅ **דוא"ל אישור ללקוח** — נשלח אוטומטית ללקוח שהשאיר אימייל (אם SMTP מוגדר).
- ⬇️ **ייצוא ל-CSV / Excel** של כל ההזמנות בלחיצה אחת (עם תמיכה מלאה בעברית).
- 🗄️ **מסד נתונים SQLite** מובנה (ללא צורך בהתקנת DB חיצוני).
- 🪶 **מינימום תלויות** — `express` + `nodemailer` (nodemailer נטען רק אם מגדירים שליחת מייל). SQLite, הצפנת סיסמאות וטוקני התחברות — על מודולים מובנים של Node.

## טכנולוגיות

| שכבה | טכנולוגיה |
|------|-----------|
| שרת | Node.js 22 + Express |
| מסד נתונים | `node:sqlite` (מובנה ב-Node) |
| אימות | scrypt (הצפנת סיסמאות) + טוקן HMAC חתום בעוגייה `HttpOnly` |
| Frontend | HTML / CSS / Vanilla JS (ללא build) |

## התקנה והרצה

דרוש **Node.js 22 ומעלה**.

```bash
# התקנת התלות
npm install

# (אופציונלי) הגדרת משתני סביבה
cp .env.example .env
# ערכו את .env — בעיקר SESSION_SECRET, ADMIN_USERNAME, ADMIN_PASSWORD

# הרצה
npm start
```

השרת יעלה על http://localhost:3000

- **אתר:** http://localhost:3000/
- **ניהול:** http://localhost:3000/admin.html

בהרצה הראשונה נוצר אוטומטית משתמש אדמין. אם לא הגדרתם `.env`, פרטי ברירת המחדל הם:

```
שם משתמש: admin
סיסמה:    admin123
```

> ⚠️ בפרודקשן — שנו את `ADMIN_PASSWORD` ואת `SESSION_SECRET` בקובץ `.env`.

## API

### ציבורי

| Method | Endpoint | תיאור |
|--------|----------|-------|
| `POST` | `/api/orders` | יצירת הזמנה חדשה |
| `GET`  | `/api/health` | בדיקת תקינות |

**גוף הבקשה ליצירת הזמנה:**

```json
{
  "name": "שם מלא",          // חובה
  "phone": "050-0000000",     // חובה
  "email": "a@b.com",         // אופציונלי
  "work_type": "סמינריון",    // חובה
  "subject": "משפטים",        // אופציונלי
  "pages": 20,                 // אופציונלי
  "deadline": "2026-09-01",   // אופציונלי
  "details": "הערות"          // אופציונלי
}
```

### מוגן (דורש התחברות אדמין)

| Method | Endpoint | תיאור |
|--------|----------|-------|
| `POST`   | `/api/auth/login`  | התחברות (מחזיר עוגיית session) |
| `POST`   | `/api/auth/logout` | התנתקות |
| `GET`    | `/api/auth/me`     | פרטי המשתמש המחובר |
| `GET`    | `/api/orders`      | רשימת הזמנות (`?status=new\|in_progress\|done\|cancelled`) |
| `GET`    | `/api/orders/export.csv` | ייצוא כל ההזמנות לקובץ CSV |
| `GET`    | `/api/orders/stats` | נתוני סטטיסטיקה לדשבורד (לפי סטטוס / סוג עבודה / יום) |
| `PATCH`  | `/api/orders/:id`  | עדכון סטטוס הזמנה |
| `DELETE` | `/api/orders/:id`  | מחיקת הזמנה |

## התראות על הזמנה חדשה

בכל יצירת הזמנה נשלחת התראה אוטומטית בכל הערוצים המוגדרים. **כל הערוצים אופציונליים** —
מה שלא הוגדר ב-`.env` פשוט מדולג, וכשל בשליחה לעולם לא מונע את שמירת ההזמנה.

| ערוץ | משתני סביבה | הערות |
|------|-------------|-------|
| 💬 **WhatsApp** | `WHATSAPP_PHONE`, `CALLMEBOT_APIKEY` | דרך [CallMeBot](https://www.callmebot.com/blog/free-api-whatsapp-messages/) — חינמי, הפעלה חד-פעמית |
| ✉️ **אימייל** | `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `NOTIFY_EMAIL_TO` | כל שרת SMTP (למשל Gmail עם App Password) |
| 🔗 **Webhook** | `NOTIFY_WEBHOOK_URL` | POST עם `{ event, order }` — לחיבור ל-Zapier / Make / n8n / Slack |

ראו דוגמאות מלאות ב-`.env.example`.

## ייצוא הזמנות

בפאנל הניהול יש כפתור **⬇ ייצוא CSV** שמוריד את כל ההזמנות כקובץ `orders.csv`.
הקובץ נוצר עם BOM של UTF-8 כך שנפתח נכון ב-Excel עם עברית, ושדות עם פסיקים/מרכאות עוברים escaping תקני.

## אבטחה — הערות

- סיסמאות נשמרות מוצפנות (scrypt + salt), לא בטקסט גלוי.
- ההתחברות מבוססת טוקן חתום ב-HMAC המאוחסן בעוגיית `HttpOnly` (לא נגיש ל-JavaScript בדפדפן).
- כל קלט המשתמש עובר ולידציה בצד שרת; פלט בפאנל הניהול עובר escaping למניעת XSS.
- לפני העלאה לפרודקשן החליפו את `SESSION_SECRET` בערך אקראי וארוך.
