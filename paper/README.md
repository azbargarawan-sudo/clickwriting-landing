# עבודה סמינריונית – אתגר קרת

תוצר: `עבודה_סמינריונית_אתגר_קרת.docx` (35 עמ', ~6,400 מילים), עם תצוגה מקדימה ב-`עבודה_סמינריונית_אתגר_קרת.pdf`.

| פונט דויד 14, רווח 1.5 | ✅ |

## הנחות שננקטו

המשתמש לא סיפק את הסיפור השני ואת שאלות המחקר שאושרו, ולכן נבחרו:

- **סיפור א'**: "דוב קוטב", מתוך *אוטוקורקט* (2024) – מזוהה מהצילומים.
- **סיפור ב'**: "שוברים את החזיר", מתוך *געגועי לקיסינג'ר* (1994) – הקובץ שנראה בצילום.
- **נושא משותף**: היאחזות דמות בודדה באובייקט לא-אנושי כתחליף לקשר אנושי.
- **שאלות מחקר**: שלוש שאלות (דמות / אובייקט / ציר זמן), ראו סעיף 1.1.

## נקודות לבדיקה לפני הגשה

1. ציטוטים ומספרי עמודים מ"שוברים את החזיר" – מסומנים בהערות אפורות בגוף העבודה.
2. אימות פרטי המקורות הביבליוגרפיים מול הקטלוג הספרייתי.
3. השלמת הפרטים האישיים בדף השער ובפרק הרפלקציה.
4. מחיקת כל הערות העריכה האפורות.

## בנייה מחדש

```bash
npm install docx
node build.js          # מייצר keret_paper.docx (העתיקו לשם הסופי)
```

- `content-1.js` / `content-2.js` / `content-3.js` – תוכן העבודה.
- `build.js` – בונה את ה-docx (RTL, דויד 14, רווח 1.5, תוכן עניינים, כותרת תחתונה).
- `toc-pages.json` – מספרי העמודים לתוכן העניינים (מופקים מה-PDF; ראו README היסטוריה).
- `pngcrop.py` – חיתוך והקטנה של תמונות הנספחים.
