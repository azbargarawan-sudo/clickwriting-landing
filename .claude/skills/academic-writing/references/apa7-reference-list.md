# רשימת מקורות: תבניות לפי סוג פריט (APA 7)

מבוסס על "הנחיות לכתיבה אקדמית על-פי כללי ה-APA", צוות הספרייה, הקריה האקדמית
אונו, מעודכן לפי Publication Manual of the APA, 7th edition (2020).

## תזכורת: ארבעת הרכיבים

```
מחבר. (תאריך). כותר. מקור.
```

נקודה מפרידה בין רכיבים. פסיק או סוגריים מפרידים בתוך רכיב.

**מה נטוי ומה לא:**

| הפריט | הכותר נטוי? | מה עוד נטוי |
|---|---|---|
| ספר, תזה, דו"ח | כן | - |
| פרק מתוך ספר ערוך | לא | שם הספר הערוך נטוי |
| מאמר מכתב עת | לא | שם כתב העת ומספר הכרך נטויים |

**במהדורה 7 אין מקום הוצאה.** רק שם ההוצאה. `דביר.` ולא `תל אביב: דביר.`

### מצגת או חומרי קורס
המצב הכי שכיח בעבודות סמסטריאליות, וגם זה שהכי הרבה סטודנטים מדלגים עליו.
```
שם משפחה מרצה, ר' (שנה). שם המצגת [מצגת הרצאה]. שם הקורס, שם המוסד.
```
```
איגל, כ' (2026). מעורבות הצוות הרב-תחומי בהשתלבותו של תלמיד [מצגת הרצאה]. הקריה האקדמית אונו.
```
אם המרצה לא הגדירה נוהל אחר, אפשר גם לציין בגוף העבודה "כפי שנלמד בקורס" ולוודא
שהמצגת נמצאת ברשימה.

## מקרים חסרים

| מה חסר | הפתרון |
|---|---|
| מחבר | הכותר עולה למקום הראשון |
| תאריך | `(ל.ת.)` בעברית, `(n.d.)` באנגלית |
| כותר | תיאור הפריט בסוגריים מרובעות |

חוסר בפרטים מזהים הוא בעצמו סימן לאיכות ומהימנות נמוכות. שקול אם להשתמש בפריט
כזה בכלל.

---

## מיון בתוך הרשימה

1. אלפביתי לפי שם המשפחה של המחבר הראשון.
2. **עברית לפני אנגלית**, בלי כותרת ביניים ובלי מספור.
3. אותו שם משפחה, מחברים שונים: לפי האות הראשונה של השם הפרטי.
4. אותו מחבר, כמה פריטים: לפי שנה, מהמוקדמת למאוחרת.
5. אותו מחבר ואותה שנה: לפי סדר אלפביתי של הכותרות, עם אות לצד השנה
   (2000א, 2000ב / 2003a, 2003b), והאות מופיעה גם בגוף העבודה.
6. מחבר יחיד קודם לאותו מחבר עם שותפים.
