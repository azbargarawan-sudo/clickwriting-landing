# סקילים

## academic-writing

כתיבה ועריכה של עבודות אקדמיות בכל נושא, לפי APA מהדורה 7, בעברית או באנגלית.
מאחד שלושה דברים: כללי אזכור מלאים, כללי הסגנון האקדמי, והכללים של `humanizer`
כדי שהטקסט לא יישמע כמו פלט של מודל.

```
academic-writing/
  SKILL.md                              הכללים שתמיד חלים
  references/apa7-reference-list.md     תבניות רשימת מקורות לפי סוג פריט
  references/lecturer-corrections.md    הערות מרצה עם דוגמאות לפני ואחרי
```

מקורות: חוברת "הנחיות לכתיבה אקדמית על-פי כללי ה-APA" של צוות הספרייה בקריה
האקדמית אונו (מעודכן ל-APA 7, 2020), מצגת כללי אזכור ורישום מקורות מקורס
הכתיבה האקדמית, והערות מרצה על עבודת סיכום שהוחזרה עם תיקונים.

מופעל אוטומטית כשמבקשים לכתוב עבודה, להוסיף אזכורים, לתקן רשימת מקורות או
לבדוק APA. אפשר גם `/academic`.

## humanizer

הסקייל המקורי. כתיבה שנשמעת אנושית בכל הקשר שאינו אקדמי: מיילים, פוסטים,
ראיונות, תמלולים. בטקסט אקדמי `academic-writing` מחליף אותו.

הסקילים נטענים אוטומטית מהריפו הזה. לשימוש גלובלי בכל הפרויקטים:

cp -r .claude/skills/academic-writing ~/.claude/skills/
