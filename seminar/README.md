# סמינריון – פרשת דרייפוס והרצל

עבודה סמינריונית לקורס 10305 "האנטישמיות במאה ה-19" (האוניברסיטה הפתוחה):
"השפעת פרשת דרייפוס על התפתחות הגותו הציונית של תיאודור הרצל: מהתבוללות ללאומיות יהודית".

המבנה לפי סיכום הפגישה עם המנחה: מבוא (כעמוד וחצי, מסתיים במסקנות), פרק ראשון (רקע היסטורי: הרצל, התנועות
האנטישמיות בגרמניה, באוסטריה ובצרפת), פרק שני (גורמים שאינם קשורים לפרשה), פרק שלישי (פרשת דרייפוס), סיכום,
רשימת מקורות. ההפניות למקורות בהערות שוליים (כנדרש בהנחיות המחלקה), הערה בסוף כל פסקה עם המקורות והעמודים; גופן David 12, רווח 1.5; כל פרק בעמוד חדש.

- `מבוא ופרק ראשון - להגשה.docx` – קובץ ההגשה למנחה: שער, תוכן עניינים, מבוא, פרק ראשון ורשימת המקורות שאוזכרו בהם בלבד.
- `סמינריון - פרשת דרייפוס והרצל.docx` – העבודה המלאה: כ-10,150 מילים כולל הערות השוליים (כ-8,500 בגוף), 89 הערות שוליים, 50 פריטים ברשימת המקורות.
- `src/*.txt` – טקסט הפרקים (`#`/`##` כותרות, `%%BIB%%` תחילת רשימת המקורות). האזכורים כתובים בטקסט בצורה `(שם משפחה, שנה, עמ' X)` וסקריפט הבנייה הופך אותם להערות שוליים (צורה מלאה באזכור הראשון, מקוצרת אחר כך) לפי `sources.js`.
- `build.js` – בונה את ה-docx: `npm install docx` ואז `node build.js` (העבודה המלאה) או
  `SUBMISSION="הגשה למנחה: מבוא ופרק ראשון" node build.js "מבוא ופרק ראשון - להגשה.docx" --only=00,01`
  (הגשה חלקית; רשימת המקורות מסוננת אוטומטית לפריטים שאוזכרו). הדגל `--inline` משאיר את האזכורים בסוגריים בגוף הטקסט (שם משפחה, שנה, עמודים) במקום הערות שוליים.

לפני ההגשה: למלא בשער שם, מספר זהות ושם המדריך, ולעדכן את תוכן העניינים אם Word לא עשה זאת בפתיחה.
