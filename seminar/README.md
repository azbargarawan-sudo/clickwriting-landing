# סמינריון – פרשת דרייפוס והרצל

עבודה סמינריונית לקורס 10305 "האנטישמיות במאה ה-19" (האוניברסיטה הפתוחה), על פי הצעת המחקר שאושרה:
"השפעת פרשת דרייפוס על התפתחות הגותו הציונית של תיאודור הרצל: מהתבוללות ללאומיות יהודית".

- `סמינריון - פרשת דרייפוס והרצל.docx` – הקובץ המוגש (שער, תוכן עניינים, מבוא, שישה פרקים, סיכום, ביבליוגרפיה; הערות שוליים; גופן David 12, רווח 1.5).
- `src/*.txt` – טקסט הפרקים בפורמט פשוט (`#`/`##` כותרות, `[[...]]` הערת שוליים, `%%BIB%%` תחילת הביבליוגרפיה).
- `build.js` – בונה את ה-docx מן הקבצים ב-`src` (דורש את חבילת `docx` מ-npm): `npm install docx && node build.js`.

לפני ההגשה: למלא בשער את שם הסטודנט/ית, מספר הזהות ושם המדריך/ה, ולעדכן את תוכן העניינים (לחיצה ימנית → עדכן שדה) אם Word לא עשה זאת בפתיחה.
