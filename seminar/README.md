# سيمنار: الذكاء الاصطناعي ودمجه في التعليم

وحدة تعليمية في العلوم للصف الخامس (أجهزة جسم الإنسان) مبنية بأداة Canva.

## الملف النهائي

`الذكاء الاصطناعي ودمجه في التعليم - سيمنار.docx` — 28 صفحة، عربي من اليمين لليسار،
تباعد أسطر مزدوج، هوامش 2.5 سم، فاصل صفحة قبل كل فصل، توثيق APA 7.

## ما يجب تعبئته قبل التسليم

| الموضع | الحقل |
|---|---|
| صفحة الغلاف | اسم المؤسسة، البرنامج، اسم الكورس ورقمه، اسم المحاضرة، الاسم الكامل، رقم الهوية، التاريخان |
| القسم العملي، "سياق التنفيذ" | `[اسم المدرسة]` و`[27]` عدد التلاميذ |
| الصفحة الأخيرة | نصّ إقرار استخدام الذكاء الاصطناعي وفق النموذج الرسمي في موقع الكورس |

## إعادة البناء بعد تعديل النصّ

النصّ كلّه في `src/content.js`. بعد أي تعديل:

```bash
cd seminar/src
npm install docx
./make.sh
```

`make.sh` يبني المستند مرّتين: مرّة لحساب أرقام صفحات الفهرس، ومرّة نهائية،
ويكرّر حتى تستقرّ الأرقام. يتطلّب `libreoffice-writer` و`poppler-utils` لحساب الصفحات.

للتدقيق على التوثيق (مطابقة الأزكار مع قائمة المراجع في الاتجاهين، الترتيب الأبجدي،
خلوّ النصّ من الشرطة الطويلة):

```bash
python3 check_refs.py
```
