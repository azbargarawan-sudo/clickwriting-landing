# פרויקט גמר: היענות לבדיקות ממוגרפיה בחברה הערבית בישראל

המרכז האקדמי פרס, החוג למנהל מערכות בריאות. מחקר איכותני מבוסס שנים עשר ראיונות עומק.

## מבנה פרויקט הגמר

שער, תוכן עניינים אוטומטי, תקציר, מבוא, סקירת ספרות, שיטת המחקר, ממצאים, דיון,
סיכום ומסקנות, רשימת מקורות, ושני נספחים: מדריך הראיון ותמלילי שנים עשר הראיונות.

היקף גוף העבודה כ-23.7 עמודים, מתחת למגבלת 25 העמודים שבחוברת הקורס. חלוקה לפי פרק:

| סקירת ספרות | 2,198 | 6.7 |
| שיטת המחקר | 982 | 3.0 |

## עיצוב

גופן David בגודל 12, מרווח שורות כפול, יישור לשני הצדדים, כיווניות מימין לשמאל,
שוליים 2.5 ס"מ מכל צד, כל פרק פותח בעמוד חדש, מספור עמודים בתחתית.

תוכן העניינים הוא שדה TOC אמיתי והמסמך מוגדר לרענן שדות בפתיחה. אם התוכן מופיע ריק,
יש ללחוץ עליו ולבחור עדכן שדה.

## המחקר

שאלת המחקר: אילו גורמים מעכבים ומקדמים את היענותן של נשים בחברה הערבית בישראל
לבדיקות ממוגרפיה, וכיצד ניתן להגביר אותה.

ארבע התמות שעלו מן הניתוח התמטי:

1. הידע כתנאי הכרחי שאינו מספיק
2. הגוף, הצניעות והמבט של הקהילה
3. החסמים היומיומיים ומערך הזימון
4. הפנייה האישית והרשת הנשית

## בדיקות שהורצו על התוצר

- 81 הציטוטים במאגר ו-51 הציטוטים בפרק הממצאים אומתו תוכנתית כמופיעים מילה במילה בתמלילים.
- התאמה דו-כיוונית מלאה בין הגוף לרשימת המקורות: 23 אזכורים, 23 פריטים, אפס יתומים לשני הכיוונים.
- שש עשרה שאלות הראיון זהות מילה במילה בכל שנים עשר הראיונות.
- אין קו מפריד ארוך באף מקום בקובץ.

## המצגת

שמונה עשר שקפים המכוסים ב-15 דקות, בחלוקה שווה בין שלוש מציגות: שער, סדר ההצגה,
רקע ונתונים, סקירת ספרות, שאלת המחקר, שיטה, המדגם, מפת התמות, ארבעה שקפי תמות,
מה המחקר מוסיף על הספרות, הממצא המפתיע, מגבלות, מסקנות, המלצות וסיום.

לכל שקף יש הערות מציג בשדה ה-Notes. חמשת הציטוטים שעל השקפים אומתו כמופיעים מילה
במילה בתמלילים, וההשמטה היחידה מסומנת ב-[...].

## בנייה מחדש

```bash
cd source
npm install docx
python3 diagram.py                       # מייצר את themes.png
node build_project.js ../פרויקט-גמר-ממוגרפיה.docx
python3 postprocess.py ../פרויקט-גמר-ממוגרפיה.docx

node build.js ../ראיונות-עומק-ממוגרפיה.docx     # הראיונות בלבד
python3 postprocess.py ../ראיונות-עומק-ממוגרפיה.docx

npm install pptxgenjs
node build_deck.js ../מצגת-פרויקט-גמר-ממוגרפיה.pptx
python3 qa_deck.py ../מצגת-פרויקט-גמר-ממוגרפיה.pptx    # גבולות, גלישת טקסט וחפיפות
```

`chapters/` מכיל את פרקי העבודה בפורמט מתויג: `#1` פרק, `#2` תת-פרק, `p` פסקה,
`q` ציטוט מוזח, `c` שורת קרדיט לציטוט, `t|` שורת טבלה, `r` ו-`R` פריטי ביבליוגרפיה
בעברית ובאנגלית, `i` תמונה, `f` כיתוב. `01.txt` עד `12.txt` הם תמלילי הראיונות,
`quotes.md` הוא מאגר הציטוטים הממוין לפי תמות, ו-`BRIEF.md` הוא התדריך שלפיו נכתבו
הראיונות ובו גם מדריך הראיון המלא.
