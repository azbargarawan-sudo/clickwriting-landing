## עיצוב

גופן David בגודל 12, מרווח שורות כפול, יישור לשני הצדדים, כיווניות מימין לשמאל,
שוליים 2.5 ס"מ מכל צד, כל פרק פותח בעמוד חדש, מספור עמודים בתחתית, ולוגו המכללה
בראש דף השער כפי שחוברת הקורס דורשת.

תוכן העניינים הוא שדה TOC אמיתי והמסמך מוגדר לרענן שדות בפתיחה. אם התוכן מופיע ריק,
יש ללחוץ עליו ולבחור עדכן שדה.

ההמלצות בפרק הסיכום, בשקף ההמלצות שבמצגת התבנית ובשקף המקביל במצגת העצמאית
ממוספרות אחת עד שש ברצף. המספור נוצר על ידי מנגנון הרשימות של Word ושל PowerPoint
עצמם ולא נכתב כטקסט, ולכן הוא יושב בצד ימין של הפסקה בכיווניות מימין לשמאל. מספר
שנכתב כטקסט יחד עם מקף היה מתהפך בכיווניות מימין לשמאל והמקף היה מוצג בצד הלא נכון.

## המחקר

שאלת המחקר: אילו גורמים מעכבים ומקדמים את היענותן של נשים בחברה הערבית בישראל
לבדיקות ממוגרפיה, וכיצד ניתן להגביר אותה.

ארבע התמות שעלו מן הניתוח התמטי:

1. הידע כתנאי הכרחי שאינו מספיק
2. הגוף, הצניעות והמבט של הקהילה
3. החסמים היומיומיים ומערך הזימון
4. הפנייה האישית והרשת הנשית

תרשים הממצאים מציג את הדרך אל הבדיקה כרצף של חמש תחנות, מידע וזכאות ועד חזרה
במועד, ומסמן בכל תחנה איזו תמה חוסמת אותה. התמה הרביעית מוצגת כרצועה החוצה את כל
התחנות, בהיותה הגורם שנמצא כמעביר את האישה מתחנה לתחנה.

## המצגות

**`מצגת-פרויקט-גמר-תבנית-המכללה.pptx` היא הגרסה להגשה.** היא בנויה על תבנית פרויקט
הגמר הרשמית של המכללה, עם הלוגו ועם שש עשרה כותרות הפרקים המוכתבות בה: שער, רקע
והצגת הבעיה, שאלת המחקר ומטרות, שתי סקירות ספרות, מסגרת תיאורטית, שני שקפי
מתודולוגיה, כלי המחקר, שלושה שקפי ממצאים, שני שקפי סיכום, המלצות ומגבלות המחקר.

בכל שקף כתיבה רציפה ואינטגרטיבית, פסקה אחת רצופה ולא בולטים, בגופן ובעיצוב של
התבנית. הטקסט מיושר לימין ולא לשני הצדדים: בפסקה מיושרת לשני צדדים השורה האחרונה
נצמדת לקצה ההתחלה, וחלק מן המציגים מיישרים אותה שמאלה גם בפסקה המסומנת כימין-לשמאל.
יישור לימין נותן את אותה תוצאה בכל מציג. מספרי השקפים הועברו מן הפינה השמאלית
התחתונה, שבה התבנית מיקמה אותם, אל הקצה הימני של עמודת התוכן.

מאותה סיבה עצמה, טקסט השקפים עטוף בתווי הבקרה U+202B ו-U+202C, שהם סימון של
כיווניות מימין לשמאל בתוך רצף התווים עצמו. מציג שאינו מכבד את מאפיין ה-rtl מפרש את
הפסקה כשמאל-לימין, ואז אלגוריתם הדו-כיווניות של יוניקוד פותר את הנקודה שבסוף
המשפט, שהיא תו נייטרלי, לפי הכיוון השגוי ומצייר אותה בקצה הימני של השורה, כלומר
לפני המשפט ולא אחריו. התווים האלה קובעים את הכיוון ברמת התו ולכן התוצאה זהה בכל
מציג. הם תווי עיצוב בלתי נראים מקטגוריית Cf ואינם משנים את הטקסט. כל 148 פסקאות
העברית במצגת נבדקו בהרצת אלגוריתם הדו-כיווניות בשני כיווני הבסיס, והתקבלה תוצאה
זהה בשניהם. הדגשות נעשות בתוך הפסקה ולא כרשימה. שקף המתודולוגיה השני נושא את טבלת
שתים עשרה המרואיינות ושקף הממצאים הראשון את תרשים הדרך אל הבדיקה.

לוגו המכללה שבתבנית המקורית היה של המרכז האקדמי למשפט ולעסקים ברמת גן, והוחלף
בלוגו של המרכז האקדמי פרס. תיבת התמונה שונתה לריבוע כדי שהלוגו לא יימתח.

הטקסט כתוב במשלב אקדמי: גוף שלישי לאורך כל המצגת, אזכורים לפי APA בכל טענה
הנשענת על הספרות, ושקף שבע עשרה נוסף לתבנית ובו רשימת המקורות. אחד עשר האזכורים
שבגוף המצגת ואחד עשר הפריטים ברשימה מוצלבים לשני הכיוונים. כל השקפים ממוספרים.

`מצגת-פרויקט-גמר-ממוגרפיה.pptx` היא גרסה קודמת בעיצוב עצמאי, שמורה למקרה שיעדיפו
מצגת מעוצבת יותר על פני התבנית.

לכל שקף בשתי המצגות יש הערות מציג בשדה ה-Notes, וכל הציטוטים שעליהן אומתו כמופיעים
מילה במילה בתמלילים.

שתי המצגות ארוזות כפי שאופיס אורז: `[Content_Types].xml` ראשון בארכיון ובלי רשומות
תיקייה. במצגת התבנית נוסף גם `notesMaster` משלו עם ערכת נושא נפרדת, משום ששקף הערות
ללא מאסטר הערות גורם ל-PowerPoint לסרב לפתוח את הקובץ. `repack.py` מבצע את האריזה
התואמת על כל קובץ OOXML.

## בנייה מחדש

```bash
cd source
npm install docx
python3 diagram_path.py                  # מייצר את תרשימי הממצאים
node build_project.js ../פרויקט-גמר-ממוגרפיה.docx
python3 postprocess.py ../פרויקט-גמר-ממוגרפיה.docx

node build.js ../ראיונות-עומק-ממוגרפיה.docx     # הראיונות בלבד
python3 postprocess.py ../ראיונות-עומק-ממוגרפיה.docx

npm install pptxgenjs
node build_deck.js ../מצגת-פרויקט-גמר-ממוגרפיה.pptx
python3 qa_deck.py ../מצגת-פרויקט-גמר-ממוגרפיה.pptx    # גבולות, גלישת טקסט וחפיפות

python3 -c "import zipfile; zipfile.ZipFile('template-original.pptx').extractall('tpl')"
python3 ~/.claude/skills/synced/pptx/scripts/add_slide.py tpl/ slide16.xml --after slide16.xml
python3 diagram_path.py                  # מייצר את שני תרשימי הממצאים
python3 fill_template.py                 # יוצר deck_template.pptx מתוך tpl/
python3 qa_template.py deck_template.pptx
```

`chapters/` מכיל את פרקי העבודה בפורמט מתויג: `#1` פרק, `#2` תת-פרק, `p` פסקה,
`q` ציטוט מוזח, `c` שורת קרדיט לציטוט, `t|` שורת טבלה, `r` ו-`R` פריטי ביבליוגרפיה
בעברית ובאנגלית, `i` תמונה, `f` כיתוב. `01.txt` עד `12.txt` הם תמלילי הראיונות,
`quotes.md` הוא מאגר הציטוטים הממוין לפי תמות, `peres_logo.jpg` הוא לוגו המכללה
שמשמש בכל ארבעת התוצרים, ו-`BRIEF.md` הוא התדריך שלפיו נכתבו הראיונות ובו גם
מדריך הראיון המלא.
