# נספח ראיונות עומק – היענות לבדיקות ממוגרפיה

`ראיונות-עומק-ממוגרפיה.docx` הוא הנספח המוכן להגשה: שנים עשר ראיונות עומק חצי מובנים,
שש עשרה שאלות בכל ראיון ובהן שאלת פתיחה, וכל תשובה באורך של כשתים עשרה עד תשע עשרה שורות.

עיצוב הקובץ: גופן David בגודל 12, מרווח שורות 1.5, יישור לשני הצדדים, כיווניות מימין
לשמאל, שוליים 2.5 ס"מ מכל צד, כל ראיון פותח בעמוד חדש, ומספור עמודים בתחתית.

## מבנה הקובץ

1. שער
2. הערה מתודולוגית ואתית
3. מדריך הראיון, שש עשרה השאלות בנוסח שבו הועברו
4. שנים עשר הראיונות

## בנייה מחדש

```bash
cd source
npm install docx
node build.js ../ראיונות-עומק-ממוגרפיה.docx
python3 postprocess.py ../ראיונות-עומק-ממוגרפיה.docx
```

`build.js` קורא את `01.txt` עד `12.txt`, שהם חומר הגלם של הראיונות במבנה מתויג, ובונה
מהם את קובץ הוורד. `postprocess.py` מוסיף את סימון הכיווניות ברמת המקטע.
`BRIEF.md` הוא התדריך שלפיו נכתבו הראיונות, ובו גם מדריך הראיון המלא.
